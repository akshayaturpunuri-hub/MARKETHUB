# 🛒 MarketHub - Online Buyer & Seller Portal

## 📖 Project Description

MarketHub is a simple Online Buyer and Seller Portal developed using HTML and CSS. It provides a user-friendly interface where buyers can browse products and sellers can register their businesses. This project demonstrates the basics of web development using HTML for page structure and CSS for styling.

---

## 🎯 Project Objectives

- Develop a basic marketplace website.
- Learn HTML page linking.
- Learn CSS styling.
- Create registration forms.
- Design responsive web pages.
- Practice navigation between multiple pages.

## ▶️ How to Run the Project

1. Download or copy the project folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension (optional).
4. Open **home.html**.
5. Right-click and choose **Open with Live Server** or double-click **home.html** to open it in a browser.
6. Navigate through the Buyer and Seller pages using the menu.
